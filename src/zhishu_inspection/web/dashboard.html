查看可复算的订单层 SQL
SELECT sum(product_amount) AS 商品金额,
       count(*) AS 完成订单数,
       sum(product_amount) / nullif(count(*), 0) AS 客单价,
       count(DISTINCT customer_unique_id) AS 唯一客户数
FROM dwd_orders
WHERE order_status = 'delivered';
这是公开历史数据分析，不代表实时经营情况；商品金额不等同于财务收入或利润。来源为 Olist 公开电商数据集。
