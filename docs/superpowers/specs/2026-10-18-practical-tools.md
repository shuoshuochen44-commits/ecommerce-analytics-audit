# 表格接入、订单查询与月份对比

面向零基础用户，继续现有可见里程碑。优先交付 CSV 模板接入、订单查询导出、完整月份比较；MySQL 等待客户表结构。

- CSV 每行一笔订单，订单号唯一；列为订单号、下单日期、省份、买家编号、商品分类、商品金额、运费、支付金额、订单状态。金额为人民币、非负且最多两位小数；状态为已完成、已发货、处理中、已取消。未提供交付日期时保持空值并给出检查提示，不推断交付时效。单笔多品类需先按业务选定分类汇总，不接受重复订单号。用户按模板导出 CSV（UTF-8 或 GB18030），最多 20,000 笔、5 MB。
- 下载模板含示例订单和示例标记，用户导入数据统一标注“用户导入，来源由提供者确认”，不声称已验证为真实交易。预检查不写入文件，显示数量、范围、金额和前五行；点击确认导入才保存。失败保留上次成功结果。导入为整表快照替换当前用户数据，保留历史版本；与模拟数据分开存放，页面可切换。
- 订单查询继承当前月份和地区，支持订单/买家编号关键词及订单状态，20 条分页，包含取消和未交付订单并明确提示。下载查询结果 CSV；报告和查询固定到同一成功数据版本。CSV 文本防公式执行。
- 选择完整月份时显示四项指标与上月比较。当前与上一月都在数据日期覆盖内才计算；上月为零不显示百分比；月份不完整和全部月份显示原因。客户数每期重新去重，保持相同地区筛选。金额用 Decimal。
- 上传仅限本机同源、要求自定义请求头、请求大小限额、固定输出路径，禁止任意 SQL 和文件路径。
- 更新桌面交付，保留用户文件；实际验证导入预览/确认/切换/失败、查询搜索/导出/分页、对比及手机布局。
