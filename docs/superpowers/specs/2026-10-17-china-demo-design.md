# 中国大陆模拟经营版与新手操作

用户已选择中国省份、人民币的模拟演示版，并要求零基础可用；沿用连续实施的合作方式。

## 交付

- 独立生成固定种子的国内电商模拟数据，覆盖 2026 年 1—9 月、31 个省级地区、8 个中文品类。金额从人民币分生成，不转换或重命名原巴西金额。全部人物和订单标识虚构。
- 原始演示数据位于 data/raw/china_demo，发布目录 artifacts/china-demo，与已有 Olist 数据和成果分开。数据说明文件随输入哈希、报告和 API 传递，明确模拟来源、币种和期间。
- 首页直接展示结果；仅月份和省份两个自动生效的选择框，以及恢复全部按钮。显示当前成功查询的范围；加载、失败和无数据均有中文说明。
- 首屏显示模拟标记、人民币单位、四个白话指标、月度趋势、中文省份和品类排名。模拟差异用于展示检查功能，不作为真实经营结论。
- 导航为看经营、数据检查、使用说明。技术版本、输入哈希、SQL 等收进可展开区域。
- 双击中文入口自动准备演示数据并打开浏览器；已有同一演示服务时复用。被其他服务占用时解释原因，不能关闭未知进程。
- 下载当前所选范围的中文独立 HTML 报告，包含模拟标记、币种、日期、省份、指标和排名；全批次技术报告仍可单独下载。

## 验证

生成结果可重复、拒绝覆盖已有目录；所有省份和品类为中文；检查规则和原始 SQL 核对通过；模拟元数据进入哈希和报告；旧数据仍保持 BRL。真实 HTTP 测试和浏览器验证自动筛选、恢复、空结果、说明导航及移动端；确认下载报告范围和数据一致。
